# Eurostat Route Analytics v1 — Streamlit

## Готовая витрина

Источник: выгрузка Google Colab `eurostat_paexcc_bulk_results.zip` (21 октября 2026); API-выборка Eurostat `avia_paexcc`, `freq=M`, `unit=FLIGHT`, `tra_meas=CAF_PAS`, `schedule=TOTAL`, 31 отчитывающаяся страна × 16 стран-партнёров, январь 2025 — сентябрь 2026.

Это *пассажирские коммерческие рейсы по парам стран*, НЕ пары аэропортов и НЕ транзит через FIR. Для сравнения годов используется фиксированный набор пар, наблюдаемых в обоих сравниваемых месяцах. Неполученные значения не приравниваются к нулю. Месяцы 2026 опубликованы с разным покрытием.

## Вариант А: отдельное приложение

Распакуйте папку и запустите в VS Code / PowerShell:

```powershell
cd D:\Eurocontrol_ETL\aviation_windows_2024_2026\eurostat_route_analytics_v1
python -m pip install pandas numpy streamlit
python -m streamlit run .\app_eurostat.py
```

Все аналитические CSV уже рассчитаны, Интернет не нужен.

## Вариант Б: добавить страницу в существующее Streamlit-приложение

1. Скопируйте `app_eurostat.py` как `pages/3_Eurostat_Маршруты.py` (или `pages/3_Eurostat_Routes.py`) в каталог рядом с существующим `app.py`.
2. Скопируйте папку `data/` рядом с новой страницей — то есть в `pages/data/` — **либо** отредактируйте константу `DATA` в файле страницы, чтобы указывать на центральное расположение CSV. Рекомендовано хранить данные проекта в `eurostat_route_analytics_v1/data` и написать: `DATA = Path(__file__).resolve().parents[1] / 'eurostat_route_analytics_v1' / 'data'`, если папка витрины лежит рядом с `app.py`.
3. Запустите существующее приложение как обычно. Страница появится в боковом меню при стандартной Streamlit-навигации `pages/`. Если в основном приложении используется кастомная навигация (`st.navigation`), нужно зарегистрировать страницу в ней отдельно.

**Не переписывайте и не заменяйте ваш основной app.py без его проверки**. В архиве отдельная работающая страница с независимыми фильтрами и графиками.

## Пересборка из исходного ZIP (локальная, без HTTP)

```powershell
python .\build_route_analytics.py --input .\eurostat_paexcc_bulk_results.zip --output .\data
```

Исходный ZIP вложен в папку комплекта. Скрипт не обращается к сети и не открывает DuckDB.

## Файлы витрины

- `data/route_monthly_panel.csv`: все пары стран × месяцы, состояния `REPORTED_VALUE`, `REPORTED_ZERO`, `NOT_RETURNED`.
- `data/route_pair_yoy.csv`: пары с флагом `comparable`, изменение и процентное YoY там, где база > 0.
- `data/route_partner_yoy.csv`: агрегаты по партнёру, с одинаковым набором пар стран в обоих годах.
- `data/route_reporting_country_yoy.csv`: аналогичные агрегаты по отчитывающейся стране.
- `data/route_coverage_monthly.csv`: месячное покрытие и отсутствующие ячейки.
- `data/route_baseline_2025.csv`: документированный объём рейсов по 16 выбранным странам-партнёрам; **не** доля всех маршрутов аэропорта.
- `data/route_analytics_report.json`: проверки целостности и ограничения.

Значения `NOT_RETURNED` не интерпретируются как реальное отсутствие трафика, и нельзя считать суммарные значения разных месяцев одинаково полными без проверки покрытия.
