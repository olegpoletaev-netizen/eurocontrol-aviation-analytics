## ВАЖНО: ОТСУТСТВУЕТ `aviation_analytics.duckdb`

В исходном ZIP этого файла нет. **Без него приложение не загрузится в Streamlit Community Cloud.** Чтобы опубликовать полный вариант:

1. На компьютере **остановите локальный Streamlit**, чтобы скопировать согласованную версию базы.
2. Скопируйте (НЕ перемещайте) `D:\Eurocontrol_ETL\aviation_windows_2024_2026\aviation_analytics.duckdb` в **корень этой папки**, рядом с `app.py`. Оригинал остаётся без изменений.
3. Проверьте отсутствие запрещённых к публикации или конфиденциальных сведений. Перед размещением в **Public** GitHub помните: любой посетитель может скачать базу.
4. При большом размере файла учитывайте ограничения GitHub (обычная загрузка через браузер до 25 MiB, git без LFS до 100 MiB); не включайте большую БД через Git LFS без проверки поддержки развёртывания. Альтернатива — сделать отдельную уменьшенную базу с сохранением необходимых таблиц/представлений и чисел (отдельная задача).
5. Локально в папке облачной сборки выполните `python -m pip install -r requirements.txt`, затем `python preflight.py`. Проверьте 113 аэропортов, 113452 строк, 37 NULL; предзапуск проверяет только структуру и общее число строк.
6. Создайте **отдельный GitHub-репозиторий** и загрузите содержимое папки (без секретов и необязательных исходных архивов).
7. На https://share.streamlit.io/ выберите **Create app → repository → main → app.py**, Python совместимый с зависимостями. Публикуйте только после подтверждения состава GitHub.
8. Откройте вкладки: Обзор, EDA, Сравнение годов, OLAP, Качество данных, Международные направления, ITS · LLBG, События, Методология.

**Путь к БД:** `Path(__file__).resolve().parent / "aviation_analytics.duckdb"`. Никаких внешних API-запросов в пользовательском приложении.

## Известные ограничения

- Это пакет для развёртывания, а не проверка приложения в облаке: реальный запуск невозможен без отсутствующей в исходном архиве базы.
- Данные Eurostat не доказывают rerouting, индекс экспозиции не сертифицирован. ITS не доказывает причинность.
- Некоторые величины могут отличаться при обновлении локальной базы/CSV; не смешивайте версии.
- Для публичной демонстрации лучше отдельная производная DuckDB с минимумом необходимых таблиц, а не оригинальный исследовательский архив.
